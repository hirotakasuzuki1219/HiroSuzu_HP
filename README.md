# 鈴木裕敬 公式サイト

鈴木裕敬のポートフォリオ兼公式サイトです。

## ファイル構成

- `index.html` - メインHTMLファイル
- `styles.css` - スタイルシート
- `main.js` - JavaScriptファイル

## デプロイ方法

### Netlify（推奨）

1. https://app.netlify.com/ にアクセス
2. アカウント作成
3. 「Add new site」→「Deploy manually」
4. このフォルダ内のファイル（index.html, styles.css, main.js）をドラッグ&ドロップ
5. デプロイ完了！

### Vercel

1. GitHubにリポジトリを作成してプッシュ
2. https://vercel.com/ にアクセス
3. 「Add New Project」でリポジトリを選択
4. 「Deploy」をクリック

## ローカルで確認

ブラウザで `index.html` を開くだけで確認できます。
